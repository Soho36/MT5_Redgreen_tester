# Wait for the breakout candle to close before selling

Frozen on 2026-11-06 before the new replays. The [earlier study](../rtl-failed-breakout-short/RESULTS.md) found that orders filled later earned more than orders filled during the high-break candle. Those groups were identified after seeing the trades. Test a tradable rule in three standalone native MT5 replays on the same NQ history and MNQ economics.

| Mode | What the EA does |
|---|---|
| Immediate | Reproduce the prior one-tick failed-breakout EA. The first bid strictly above the last red candle's high during the next available M30 candle submits the buffered sell stop. The trade ledger, event file and MT5 totals must agree with the frozen original before running the other modes. |
| Delayed | The same high break starts a watch for a subsequent bid at or below the planned sell stop during the rest of this M30 candle. That touch retires the setup. A touch before the break is irrelevant. If the setup survives, attempt submission on the first quote of the following M30 candle. |
| Plain delay | Start watching the buffered low at the first quote of the M30 candle after the red signal. Any bid at or below the planned sell stop during that candle retires the setup, including the opening quote. Surviving setups use the same next-candle submission and replacement rules as delayed. This control measures whether the high-break requirement contributes beyond the delay. |

Every order uses the original red low minus 0.25 points as entry and original red high plus 0.25 points as stop. Use those actual levels for the 1R candle-close exit. On a new chart-bar opening the broker processes existing orders first. An unqualified watch expires. A qualified watch is retired if this is outside the same session/trading window, outside the next scheduled M30 slot, or at/after the calendar flatten time. An open position also precludes submission. A newly completed red candle supersedes the surviving old setup. Finally, if the opening quote is already at or below the requested sell stop, discard it. A valid order can then fill only on a later quote. Green/doji bars can leave a submitted order resting until the usual replacement or session rules cancel it. Each red signal permits one submission attempt.

Use the prior trade windows, early-close calendar, session flatten/fallback, uncapped red run, M30 signals, one-minute OHLC model, one MNQ and $1.05 per round trip. The terminal date range and study-period cuts match the prior experiment. Report 2016–19, 2020 through September 2026 and pooled performance, annual results, net PF, risk-normalized expectancy, drawdown and another $1/$2 per trade. Test whether delaying improves net results versus immediate and whether the high break helps versus plain delay. Inspect trade overlap with the original later-fill group. A positive result should survive both eras and added costs before considering a forward test.

All runs use a dedicated tester-only EA. The generated quotes permit an ordered native replay, although the actual historical intraminute price path is unknown. Only the original study's timing split motivated this test. No parameter search is part of this protocol.
